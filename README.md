# BIPZILLA Clothing Brand — Streamlit Demo

A dummy ecommerce-style website for a clothing brand using your original artwork.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Cloud
1. Upload the **whole folder** to GitHub.
2. In Streamlit Cloud, create a new app.
3. Select your GitHub repo.
4. Main file path: `app.py`.
5. Deploy.

## Notes
- This is a demo store only.
- The cart and checkout are fake.
- Product prices are dummy UK prices.
- The menu is in the sidebar so it will show clearly on Streamlit Cloud.
