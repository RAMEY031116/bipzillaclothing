# BIPZILLA Streamlit Demo Website

This is a fully working dummy Streamlit website for a T-shirt / hoodie / sweatshirt brand using your uploaded artwork.

## How to run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## What is included

- Home page with hero section
- Shop page with filters, fake prices and product cards
- Collections page
- About page
- Contact page with a working demo form
- Cart page with add/remove items and dummy checkout
- Product mockup images generated from your uploaded artwork
- Logo based on your uploaded BIPZILLA text logo

## Important

This is a demo only. No real checkout or email sending is connected. Replace dummy emails, shipping text and product prices before going live.

Your uploaded artwork is saved only inside the project assets folder for this demo package. It is not changed in the original art files; mockups are separate preview images.
